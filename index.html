🚀 Quick Start

# Install
$ npm install && npx playwright install chromium
# Full 14-step pipeline
$ npm run full -- --url https://example.com --max-pages 50
# Individual phases
$ npm run crawl    # Steps 1-3: Crawl + Discover
$ npm run analyze # Step 3: Deep analysis
$ npm run generate# Steps 4-5: Generate + Prioritize
